# tests/eval/ — AI 평가셋 (담당: ai)

`services/ai.py`가 발화를 제대로 해석하는지 재는 곳이다. 1차 통과 기준: **20개 중 18개 이상 정답, 지연 중앙값 2초 이하** (10/18).

## 파일

| 파일 | 내용 | 상태 |
| --- | --- | --- |
| `utterances.jsonl` | 발화 25개, 한 줄에 하나 | 완료 |
| `run_eval.py` | 발화마다 `analyze()`를 불러 정답과 비교하고 정확도·지연을 출력 | 완료 |

## 한 줄 형식

```json
{"id": "create-01", "now": "2026-10-08T10:00:00+09:00", "tasks": [], "text": "내일 오후 3시까지 보고서 검토 추가해줘", "expected": {"action": "create_task", "args": {"name": "보고서 검토", "due_at": "2026-10-09T15:00:00+09:00", "offset_minutes": null}}}
```

- `now`: 평가 기준 시각. "내일"을 계산하는 기준이라 고정한다.
- `tasks`: 그 시점의 미완료 업무 (`item_id`, `name`, `due_at`, `status`). 완료·변경·재질문 문항에 필요하다.
- `pending` (선택): 직전 재질문 Decision. 재질문에 대한 대답 문항에만 넣는다.
- `expected`: 정답 `action`과 비교할 `args`만 적는다.

## 구성 (25개)

| 분류 | 개수 | 예 |
| --- | --- | --- |
| 등록 | 5 | "내일 오후 3시까지 보고서 검토 추가해줘" |
| 조회 | 3 | "오늘 할 일 알려줘" |
| 완료 | 3 | "보고서 검토 완료했어" |
| 마감 변경 | 3 | "보고서 마감 두 시간 미뤄줘" |
| 알림 설정·변경 | 3 | "두 시간 전 말고 30분 전에 알려줘" |
| 모호 → 재질문 | 4 | "보고서 알림 설정해줘" (이름에 "보고서"가 들어간 업무가 2개일 때), "내일 오후 3시까지 할 일 하나 추가해줘" |
| 재질문에 대한 대답 (`pending`) | 4 | "어떤 업무를 완료할까요?" → "내일 오후 3시까지" (질문과 안 맞으면 다시 재질문) |

결과는 knowledge 레포 `projects/eureka-desk-pet/ai/eval-YYYY-MM-DD.md`에 기록한다.
